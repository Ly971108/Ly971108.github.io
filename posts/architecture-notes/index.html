本站技术架构备忘

2026-10-22

这个网站的技术方案抄了 Felix Rieseberg 的作业，核心有五件事：

1. 烘焙光照

浏览器的实时灯光做不出柔和的多重反弹，所以房间的光照在 Blender 里用 Cycles 路径追踪离线烘焙成贴图，运行时按灯光状态混合。

2. 内容桥

文章以 Markdown 存放在 content/posts/，构建脚本把它们注入首页的 template 标签，3D 场景启动时解析 template 拿到结构化数据，再画到 CRT 屏幕上。

3. 降级管线

没有 WebGL2、软渲染、用户主动选择、无 JavaScript——四种情况都会得到完整的静态版本，内容一致。

4. 纯静态

GitHub Pages 托管，构建在本地完成，Actions 只负责部署。

5. 对抗 QA

用子 agent 互相找茬：卡片后面的链接能不能点、快速切频道会不会竞态、有没有残留占位文案。
